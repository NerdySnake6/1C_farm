# Молочная ферма Луговая 1.2.5

Поставка для учебной платформы 1С:Предприятие 8.3.27.1688. Два исправления формы бронирования проверены через интерфейс. Последовательный SM01–SM12 на чистой базе из итогового DT 1.2.5 завершён 21–22.11.2026: 12/12 PASS с уточнением SM10 для новой брони.

## Установка и исходники

- [DT 1.2.5](deliverables/Farm_Lugovaya_v1.2.5.dt) — конфигурация, демонстрационные операции, пользователи и расписание. Восстановите в отдельную пустую файловую базу через Конфигуратор.
- [CF 1.2.5](deliverables/Farm_Lugovaya_v1.2.5.cf) — конфигурация. Перед обновлением существующей базы сохраните резервную копию.
- [Исходники XML и BSL](configuration/) — версия 1.2.5.
- [SHA-256 DT и CF](Документация/04_Тестирование/Протоколы/Точечный_smoke_1.2.5/SHA256.txt)
