# Соглашения
AGENTS.md — основной источник правил. Русский BSL, локальный стиль отступов, сохранение BOM/окончаний строк, клиент/сервер и Экспорт. XML: сохранять UUID и связи метаданных. configuration/ — реализация; scripts/bsl — заготовки, которые нужно согласовывать для генерируемых участков. Старые генераторы могут перезаписать текущие исходники. После существенной правки обновить docs и нужную заметку. Общая документация использует пути от корня Git и переносимые обозначения; реальные пути Serena/Java остаются в локальном MCP-конфиге. Порядок переноса: docs/serena.md.
