# UI-тесты «Молочной фермы Луговая»

Сценарии основаны на приёмке поставки 1.2.5. Они проверяют рабочий стол, переходы между разделами, карточки продукции, цены, доступные остатки, права рабочих ролей и цикл создания, проведения и снятия брони.

## Запуск на macOS

Понадобятся Python 3.11 или новее, графический сеанс macOS и учебная платформа 1С 8.3.27.1688. Распакуйте `vanessa-automation-single.1.2.043.47.zip` и поместите EPF в `.build/vanessa/tools/vanessa-automation-single.epf`. [Официальный релиз Vanessa Automation](https://github.com/Pr-Mex/vanessa-automation/releases/tag/1.2.043.47).

В базе с конфигурацией из этой ветки войдите как **Администратор**. На рабочем столе откройте **Отчёты → Запустить автотесты**. При первом запуске выберите `tests/vanessa/run.command` из локальной копии репозитория. 1С запомнит файл в настройках пользователя и откроет его в Terminal. Если файл переместится, при следующем нажатии 1С снова предложит его выбрать.

Команду также можно открыть в Finder или выполнить из корня проекта:

```sh
./tests/vanessa/run.command
```

При первом открытии внешней обработки подтвердите запуск официального EPF в окне менеджера тестирования. Менеджер запускается в своей файловой базе. Тестовый клиент открывает отдельное окно с копией фермы из `deliverables/Farm_Lugovaya_v1.2.5.dt`. Для каждого прогона создаётся новая копия фермы. Сценарии переключают пользователей последовательно.

Отчёты и журналы записываются в каталог `.build/vanessa/run-*`, путь к которому выводится в терминале. В нём находятся `steps.log` с шагами, `status.txt` со статусом Vanessa и `junit/` с отчётами XML. Нулевой код завершения означает успешный прогон.
