## Безопасное тестовое окружение
Для Vanessa каждый запуск `scripts/run_vanessa_tests.py` назначает новую базу
`.build/vanessa-runs/<метка>/base`: восстановление DT 1.2.7 и загрузка текущих XML.
Менеджер работает в отдельной пустой базе `manager`. См. [Vanessa](vanessa.md).
Любая кнопка/команда, создающая или изменяющая данные, допустима только в такой базе.
Рабочие базы и копии с ручными учебными операциями не использовать как фикстуры.
Старые FarmTests ожидают демонстрационные остатки 75, 15, 12; это условие старого
набора, а не требование ко всем будущим сценариям.
Восстановление DT, создание пользователей, тестовых документов и пересоздание
данных считать изменяющими операциями. Хранить учётные данные вне Git и отчётов.
